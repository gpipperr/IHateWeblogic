                 (prefix DEV -> CLN), start, smoke test, way back - all
                 successful.
               Both are documented in clone_golden_image.md section 5.
  Important  : - !!! After the clone, the domain scripts of the clone
                 (stopWebLogic.sh ...) point to the AdminServer of the
                 SOURCE (ADMIN_URL=t3://<source-host>:7001). stopWebLogic.sh
                 on the clone then STOPS THE SOURCE if the network is open.
                 -> Step 5.1 before any start / stop on the clone; until
                 then stop only with ADMIN_URL=t3://localhost:7001
                 (step 9.1). (Found at the customer 2026-11-10.)
               - The clone must NEVER run with the RCU prefix of the source.
                 Two domains in one OPSS store (roles, passwords, keys) are
                 not allowed. That is why the autostart is off before the
                 clone (step 1) and the clone starts completely only after
                 step 9.
               - Only exception: steps 7/8. There only the AdminServer of the
                 clone starts briefly against the source prefix, so that
                 Oracle can copy its content into the new prefix. The source
                 prefix is only read.
               - In steps 7/8 the clone must reach BOTH databases:
                 <old-db-host> (read, old OPSS store) and <NEW_DB> (write).
                 From step 9 on it no longer needs <old-db-host>.
               - The clone uses the same application databases (logins in
                 cgicmd.dat). Scheduled Reports jobs of the source are moved
                 aside before the first start (step 5).
               - Passwords are only asked hidden (read -s) and passed through
                 the environment - never on a command line, in a file or in
                 a log.

PREREQUISITES
================================================================================

  - Decided before the appointment:
      <clone-host>    host name of the clone (FQDN)
      <clone-ip>      IP address of the clone
      <NEW_PREFIX>    new RCU prefix, letters / digits only, max. 12
                      characters
      <NEW_DB>        new RCU database as host:port/service, e.g.
                      <new-db-host>:1521/<NEW_SERVICE> (PDB service, not
                      the CDB)
  - The source is hardened to loopback (localhost) - see
    ../FormsReports14_linux_localhost/README.md and
    ../FormsReports14_linux_localhost/Localhost_cookbook_en.txt.
    Without the hardening the clone keeps many more host-name places
    (clone_golden_image.md section 3); clone_check_fmw.sh lists them.
  - DBA with the SYS password for <NEW_DB> (step 6, approx. 10 minutes).
    Database 19c or newer, character set AL32UTF8 (RCU checks this itself
    and stops otherwise).
  - Network: clone -> <old-db-host>:1521 AND clone -> <NEW_DB>:<port> open
    (firewall / allow list). Check in step 0.
  - VM team for the clone (step 3) - the clone process or step 4 sets the
    new MAC / IP.
  - TLS certificate for <clone-host> (or the existing certificate already
    covers the name, step 10.3).
  - Passwords that are asked hidden: WebLogic admin, SYS (DBA), password
    of the new schemas (choose it new, store it in the password safe),
    Reports server administrator (<identifier> in rwserver.conf, step 12.2).
  - clone_check_fmw.sh version 2026-11-10.8 or newer in $TOOLS (from
    ihw_customer_tools_linux.zip, 70-Customer-Projects/tools/). Older
    versions do not know the checks of steps 5.1 - 5.3.

STEP 0: Set the variables  (in EVERY new terminal, as oracle)
================================================================================

  # Replace the e.g. values by the real paths of this host. The values
  # in <...> are decided before the appointment (PREREQUISITES).

  export ORACLE_HOME=/u01/app/oracle/fmw

  export DOMAIN_HOME=/u01/app/oracle/domains/fr_domain

  export TOOLS=/u01/app/oracle/tools

  export WORK=/u01/app/oracle/install/clone_2026-11

  export LOGDIR=$WORK/logs

  export BACKUP=$WORK/backup

  export WLST=$ORACLE_HOME/oracle_common/common/bin/wlst.sh

  export REPSRV=repserver01
  # name of the standalone Reports server (as in rwserver.conf)

  export SRC_HOST=<source-host-short>
  # short host name of the SOURCE (without domain part); it also finds
  # the long name

  export OLDPFX=SRC
  # RCU prefix of the source - example value SRC, use the real one

  export NEWPFX=<NEW_PREFIX>

  export OLDDBHOST=<old-db-host>

  export OLDDB=$OLDDBHOST:1521/<OLD_SERVICE>

  export DBCONN=<NEW_DB>

  mkdir -p $LOGDIR $BACKUP

  echo "NEWPFX=$NEWPFX  DOMAIN_HOME=$DOMAIN_HOME"
  # Expected: NEWPFX=<your new prefix>  DOMAIN_HOME=/u01/app/oracle/...
  # Still <NEW_PREFIX>? -> repeat the line export NEWPFX=... with the real
  # value.

  echo "SRC_HOST=$SRC_HOST  OLDPFX=$OLDPFX  OLDDBHOST=$OLDDBHOST"
  # Expected: three real values. EMPTY or <...>? -> repeat the export.
  # (An empty value makes the greps of later steps match every line.)

  ls $WLST
  # Expected: the path is shown (no "No such file")

  echo "DBCONN=$DBCONN"
  # Expected: host:port/service of the NEW database, not <old-db-host>

  # Only on the clone (PART B) - does it reach both databases?

  for _db in $OLDDB $DBCONN; do _h=${_db%%:*}; _p=${_db#*:}; _p=${_p%%/*}; timeout 5 bash -c "</dev/tcp/$_h/$_p" && echo "OK      $_h:$_p" || echo "MISSING $_h:$_p"; done
  # Expected: 2 lines OK
  # MISSING -> clear the firewall / allow list, do NOT start step 6 before

================================================================================
STEP 6: Create the new RCU prefix  (as oracle on the clone, with the DBA,
        domain stopped)
================================================================================

  # Same components as the source prefix. RCU creates its own tablespaces
  # <NEW_PREFIX>_IAS_... (agree with the DBA; to use an existing
  # tablespace, append -tablespace <name> per component).

  read -s -p "SYS password new DB: " SYSPW
  echo

  read -s -p "Password for the new schemas: " NEWPW
  echo

  # Check that the prefix is still free:

  printf '%s\n' "$SYSPW" | $ORACLE_HOME/oracle_common/bin/rcu -silent -listSchemas -databaseType ORACLE -connectString $DBCONN -dbUser sys -dbRole sysdba -f | grep -i "$NEWPFX"
  # Expected: no output (prefix free)
  # Lines with <NEW_PREFIX>_... -> STOP, choose another prefix

  # Create: RCU reads the passwords from standard input - first line SYS,
  # then one per component, WLS needs two (WLS_RUNTIME).
  # So: SYS + 7 x the new password.

  printf '%s\n' "$SYSPW" "$NEWPW" "$NEWPW" "$NEWPW" "$NEWPW" "$NEWPW" "$NEWPW" "$NEWPW" | $ORACLE_HOME/oracle_common/bin/rcu -silent -createRepository -databaseType ORACLE -connectString $DBCONN -dbUser sys -dbRole sysdba -schemaPrefix $NEWPFX -component STB -component OPSS -component IAU -component IAU_APPEND -component IAU_VIEWER -component WLS -f 2>&1 | tee $LOGDIR/06_rcu.txt
  # Expected at the end (test run):
  #   Common Infrastructure Services     Success
  #   Oracle Platform Security Services  Success
  #   Audit Services                     Success
  #   Audit Services Append              Success

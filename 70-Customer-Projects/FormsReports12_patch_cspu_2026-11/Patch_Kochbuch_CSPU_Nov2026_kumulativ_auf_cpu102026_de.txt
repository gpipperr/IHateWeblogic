SCHRITT 4: Server-JDK 8u513 einspielen  (als oracle, README 3.1)
================================================================================

  Hintergrund: Java CSPU November 2026 (MOS CPU435). 8u513 (Build b04,
  Sicherheits-Basislinie 1.8.0_513-b04) ist kumulativ: es schliesst die
  Java-8-CVEs des November (betroffen bis 8u511-b33), den Alert
  CVE-2026-91403 (Okt) und den eMudhra-Alert CVE-2026-114820 (betroffen
  8u511-b32). KA1182 nennt 18143322 ("JDK 8 latest", Version im ZIP
  pruefen); fest auf 8u513 zeigt 40239638 (CPU435).
  Lizenz: Java, das ausschliesslich Oracle-Produkte betreibt, faellt unter
  die Ausnahme aus MOS Doc ID 1557737.1.

  Kundenumgebung: In $ORACLE_HOME/oui/.globalEnv.properties stehen
  die Eintraege JAVA_HOME und JAVA_HOME_1_8 = /oracle/java/jdk - der Pfad
  liegt ausserhalb von ORACLE_HOME (KB175049 erfuellt) und ist versionsneutral.
  Ist /oracle/java/jdk ein Link (nach dem Oktober-Lauf: ja), ist das JDK-
  Update EIN Link-Wechsel - keine Konfigurationsdatei (.globalEnv.properties,
  setDomainEnv.sh, Node Manager) wird angefasst.

  ----------------------------------------------------------------------------
  4.1 Was ist $JDK_LINK heute?
  ----------------------------------------------------------------------------
  ls -ld $JDK_LINK

  ls -d $NEW_JDK_BASE/*

  $JDK_LINK/bin/java -version
  # "lrwx... jdk -> jdk1.8.0_xxx"  Link               -> 4.2, dann 4.4 a)
  # "drwx... jdk"                  echtes Verzeichnis -> 4.2, dann 4.4 b)
  #                                (nach dem Oktober-Lauf: Link auf 8u511)

  ----------------------------------------------------------------------------
  4.2 Neues JDK NEBEN das alte legen  (nicht drueberkopieren - KB175049)
  ----------------------------------------------------------------------------
  TGZ=$(ls $STAGE/jdk-8u513*linux-x64*.tar.gz)

  echo "Archiv: $TGZ"
  # Erwartet: genau eine Datei. LEER -> Schritt 1 / Inhalt des JDK-ZIPs
  # pruefen (unzip -l $PATCH_DIR/18143322/p18143322_*.zip bzw. 40239638)

  NEW_JDK=$NEW_JDK_BASE/$(tar -tzf "$TGZ" | head -1 | cut -d/ -f1)

  echo "neues JDK: $NEW_JDK"
  # Erwartet: /oracle/java/jdk1.8.0_513

  cd $NEW_JDK_BASE
